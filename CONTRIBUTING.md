# Contributing

Keep contributions within the synthetic learning fixtures and local-workspace scope of this repository. Do not add learner data, provider credentials, SMTP secrets, raw traces, or private deployment files.

Run the offline test suite before opening a Pull Request. Live provider and SMTP checks are opt-in and must never be required for normal tests.

Use a feature branch and Pull Request. Explain skipped external checks and update the relevant documentation when configuration or data boundaries change.
